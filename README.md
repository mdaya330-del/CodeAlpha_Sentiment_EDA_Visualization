# CodeAlpha_Sentiment_EDA_Visualization

## Project Title
Product Reviews Data Analytics Project

## Tasks Covered
This project covers three CodeAlpha Data Analytics tasks:

1. Task 2: Exploratory Data Analysis (EDA)
2. Task 3: Data Visualization
3. Task 4: Sentiment Analysis

## Project Idea
The project analyzes customer product reviews. It studies ratings, product categories, review text, and customer sentiment. The goal is to understand customer satisfaction and identify common positive and negative patterns.

## Files Included
- `product_reviews.csv`: sample dataset of product reviews
- `main.py`: Python code for cleaning, EDA, visualization, and sentiment analysis
- `outputs/`: generated automatically after running the code

## How to Run
1. Install requirements:
   ```bash
   pip install pandas matplotlib
   ```

2. Run the project:
   ```bash
   python main.py
   ```

3. Check the `outputs` folder.

## Outputs Generated
- `processed_reviews_with_sentiment.csv`
- `analysis_summary.txt`
- `sentiment_distribution.png`
- `average_rating_by_category.png`
- `reviews_by_category.png`
- `average_rating_over_time.png`

## Main Questions Answered
- Which product categories have the highest average ratings?
- What is the distribution of positive, negative, and neutral reviews?
- Which products have the best customer feedback?
- How do ratings change over time?
- What issues appear in negative reviews?

## Main Insights
- Positive reviews often mention quality, comfort, design, and usefulness.
- Negative reviews often mention weak quality, bad smell, leakage, slow performance, or uncomfortable products.
- Categories with higher average ratings show better customer satisfaction.
- Businesses can use sentiment patterns to improve product quality and customer experience.
